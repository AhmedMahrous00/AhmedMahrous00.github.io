The reflexivity threshold: A phase transition for multi-agent performative prediction

Ahmed Mahrous and Roberto Di Pietro

NeurIPS 2026 · Accepted · 2026

Overview

When predictions change the data that future models learn from, interactions between learners can amplify feedback. We study a spectral threshold separating stable retraining from worst-case learning failure.
