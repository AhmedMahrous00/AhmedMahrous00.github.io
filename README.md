# Ahmed Mahrous — academic homepage

Static academic website published using GitHub Pages at https://amahrous.com/.

## Update

Edit `publications.json` for metadata and TL;DR summaries, `abstracts.json` for complete author-written abstracts, and `build.py` for the profile and layout. Each paper's PDF lives at `docs/papers/<slug>/paper.pdf`, beside its HTML page and `citation.bib`. `pdf_source` records the original public source. Historical `/pdfs/<slug>.pdf` links remain available.

`content/<slug>.html` contains the complete article body. Where original LaTeX-derived HTML is available, equations use MathML, tables use HTML, and figures use the original artwork. A `content/native-<slug>.json` manifest records the source and conversion checks. The remaining articles use PDF-derived text with exact extracts for content that cannot be faithfully reconstructed. Published metadata and citations are maintained separately from the article body.

Rebuild pages:

```sh
python3 build.py
```

To regenerate PDF-derived full text after replacing a manuscript, install `requirements.txt`, run `python3 scripts/extract_fulltext.py` for the affected paper, check the output against the PDF, and rebuild. Do not overwrite native HTML fragments with PDF extraction. Use `python3 scripts/native_stable_pump.py` for Stablecoins and PumpSense. For FinMoji and the cross-cultural article, prepare a cache directory containing `<slug>.html` downloaded from each manifest's `html_source` and an extracted `<slug>/` folder downloaded from `tex_source`, then run `python3 scripts/build_native_emoji_articles.py <cache-directory>`. Verify abstracts separately after a manuscript change.

Run `python3 scripts/check_site.py` before publishing to verify article content, equations, citations, figures, and local links.

Reflexivity Threshold's PDF and native HTML are synchronized with arXiv `2610.29577v1`. To repeat that import, cache the versioned HTML, PDF and TeX archive as `reflexivity.html`, `reflexivity.pdf` and `reflexivity.tar`, then run `python3 scripts/import_reflexivity_arxiv.py <cache-directory>` and rebuild. The source version and checksums are recorded in `content/native-reflexivity-threshold.json`.

Text and math crops in Reflexivity Threshold and Financial Microblog Emojis have been replaced with native HTML and MathML. `scripts/native_paper_passages.py` records the PDF-checked transcriptions and can apply them to the original extracted fragments. The source PDFs and scientific wording are unchanged. Figures blend into the active page theme through CSS; printing retains the original graphic colors.

Commit the updated source and `docs/` files. GitHub Pages deploys branch **main**, folder **/docs**.

## Markdown for agents (no paid dependency)

The build now requires Python 3 and Node.js 18+ (no npm install). `python3 build.py` generates the normal HTML and, from that same public HTML, `docs/index.md`, `docs/cv.md`, `docs/papers/<slug>/index.md`, `docs/llms.txt`, and `docs/llms-full.txt`. Each HTML page links to its Markdown alternative; the canonical HTML sitemap is unchanged. No source manuscript is modified. Run `node scripts/build_markdown.cjs --check` to check that the generated outputs match the built site; also run the existing `python3 scripts/check_site.py`. Keep the generated files committed under `docs/`.

The exporter keeps publication metadata, abstracts, citation blocks, scientific sections, hyperlinks, LaTeX annotations from MathML, and tables (HTML inside Markdown to preserve spans and cell structure). Images stored as files are linked; inline binary figures are linked to their original HTML article instead of copied as base64. The source HTML and PDFs remain authoritative, especially for figure-only evidence, complex typesetting and PDF-extracted text. No summaries are generated by a language model. `llms-full.txt` is a large combined convenience file; individual paper Markdown pages are more efficient to retrieve.

### Optional Cloudflare content negotiation

Static Markdown and `llms.txt` work without a Worker as soon as GitHub Pages publishes them. To support agents using `Accept: text/markdown` at normal page URLs:

1. First merge and verify the static files at `https://amahrous.com/index.md` and `https://amahrous.com/papers/reflexivity-threshold/index.md`.
2. In Cloudflare Workers & Pages, create a Worker on the Free Workers plan. Paste the ES module in `cloudflare/markdown-worker.mjs` into the editor and deploy it.
3. In the Worker's Settings → Domains & Routes, attach a **Route** of `amahrous.com/*` to the existing zone (not a Custom Domain, and do not change DNS). Choose fail-open if available. This route invokes the Worker for normal requests too, so monitor the daily free request quota. The Worker only transforms GET/HEAD requests for supported page paths when the client explicitly prefers Markdown. It forwards PDFs, assets, robots.txt and Search for Agents unchanged. If the route interferes with Search for Agents, remove the route or explicitly exclude `amahrous.com/.well-known/*` using a route with no Worker.
4. Test both `curl -i -H 'Accept: text/markdown' https://amahrous.com/papers/reflexivity-threshold/` and `curl -i -H 'Accept: text/html' https://amahrous.com/papers/reflexivity-threshold/`. The former should return `text/markdown; charset=utf-8`, the latter HTML. Both negotiated responses include `Vary: Accept`. Markdown variants are not cached at the HTML URL. Test the homepage, CV, PDFs, and `/.well-known/search` too. Remove the Worker route if any live regression occurs.

Run `node cloudflare/markdown-worker.test.mjs` for mock-origin tests. The Worker is optional and must be deployed separately in Cloudflare. Do not grant a broad API token for this setup. Search for Agents and crawler preferences are managed separately.
